# USDA nutrition references

Choose the reference that answers the question. Call `LoadSkill` with `name` set to `usda-nutrition` and the relevant relative `path`.

- For general dietary guidance, food groups, or considerations for a particular stage of life, read `references/dietary-guidelines-usda.md`.
- For a daily serving count at a given calorie level, read `references/daily-servings-by-calorie-level-usda.md`. Find the food group's row and the calorie column, then report the count or range together with a serving-size example from that row. The table covers 1,000 to 3,200 calories in 200-calorie steps.
